Hide the home indicator across iOS with a focused standalone tweak.

### Features

- Targets the home indicator in apps, on the Home Screen, on the lock screen and in the app switcher.
- Hides only the visual indicator while preserving native gesture containers and layout.
- No settings pane. Install to enable; uninstall and respring to restore the bar.
- Runs in SpringBoard only with no background daemon or continuous polling.

### Requirements

Requires **iOS 26.0 or later** with a compatible rootless or native RootHide jailbreak. Older iOS versions are not supported by these packages.

Device behavior has not yet been confirmed. Host checks and package validation passed, but visual coverage and swipe gestures still require device verification.

### Downloads

- **Standard rootless:** `com.sahinkaa.nohomebar26_1.0_iphoneos-arm64.deb`
- **Native RootHide:** `com.sahinkaa.nohomebar26_1.0_iphoneos-arm64e.deb`

Install only the package matching your jailbreak. The native RootHide package installs directly without RootHide Patcher. Disable other home-bar tweaks before testing then respring after installation.

App safe areas, keyboard spacing and app-drawn bottom bars remain unchanged. CPU and battery impact have not been benchmarked.

Source code, build instructions and SHA-256 checksums are included.
